# 🏥 Patient Case-Taking Software (MediKiosk)
### **Smart India Hackathon (SIH) Problem Statement ID: 26047**

- **Project Name**: **Patient Case-Taking Software**
- **Organization**: All India Institute of Ayurveda (AIIA)
- **Ministry**: Ministry of Ayush
- **Theme**: MedTech / BioTech / HealthTech
- **Platform**: JSR Healthcare & MediKiosk by **Ankit Chaudhary**

---

## 🛠️ Complete Technology Stack

### 1. Frontend Technologies
- **Core Framework**: React 18
- **Build Tool**: Vite 5
- **Language**: TypeScript
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **UI & Animations**: Framer Motion, Canvas Confetti, Lucide React Icons
- **Data & Charts**: Recharts
- **PDF & QR Code**: jsPDF, QRCode.react
- **Voice Engine**: Web Speech API (STT & TTS in 11 Indian Languages)

### 2. Backend Technologies
- **Runtime**: Node.js
- **API Framework**: Express.js
- **Real-Time Sockets**: Socket.io
- **Security**: Helmet, CORS, Express Rate Limit, JWT, BcryptJS
- **Document Handling**: Multer (Uploads), SheetJS / XLSX (Excel Exports)
- **Logging**: Morgan

### 3. Database Architecture
- **Primary Database**: Supabase (PostgreSQL 15 with Row Level Security)
- **NoSQL Support**: MongoDB (Mongoose)
- **Resilient Fallback**: In-Memory & Local JSON Store (`data-store.json`)

### 4. Healthcare AI & National Compliance
- **Clinical Tree Engine**: Adaptive SOCRATES (16 Clinical Branches)
- **Emergency Triage**: Code Red / Code Yellow Red-Flag Screening
- **Ayurveda Framework**: Dashavidha & Ashtavidha Pariksha + Prakriti Assessment
- **Prescription AI**: OCR Digitization & Drug-Drug Interaction Warnings
- **National Standards**: ABDM (ABHA Sandbox M1/M2/M3), HL7 FHIR R4 Bundles, DPDP Act 2023 Consent
